## Cómo usar este documento

Responder primero con palabras propias, referencias, ejemplos y descartes. No hace falta definir todo de una vez. Una respuesta puede ser provisional, pero debe indicar qué está decidido y qué sigue en exploración.

Cada decisión posterior debería clasificarse como:

- **Decidido:** forma parte de la identidad.
- **En exploración:** todavía se están comparando opciones.
- **Descartado:** no representa a Vértice CR.
- **Pendiente:** falta tomar la decisión.
